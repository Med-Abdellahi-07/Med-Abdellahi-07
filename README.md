Artificial Intelligence student at Université de Nouadhibou, Mauritania.

## What I work on

- Full-stack web applications, from database design and security rules to the user interface
- Offline-first Progressive Web Apps
- AI-assisted tools grounded in real documents (retrieval-augmented generation)
- Multilingual interfaces, including right-to-left Arabic

## Featured project

### [Neuron](https://github.com/Med-Abdellahi-07/neuron-showcase)

An offline-first study companion for university students, with a course-grounded AI assistant, ranked quizzes, spaced review, a weekly timetable and a space chat, in Arabic, French and English. It is in production and used by enrolled students. I identified the problem, designed the product and its features, made the architecture and privacy decisions, directed the implementation using AI-assisted development (Claude as coding assistant), tested it with real students, and run it in production.

Public mirror with full history, architecture diagram and screenshots: [neuron-showcase](https://github.com/Med-Abdellahi-07/neuron-showcase)

## Internship project

### [Equipment maintenance tracker — SNIM](https://github.com/Med-Abdellahi-07/projet-im)

Web application to track industrial equipment, breakdowns and maintenance interventions, built during my internship at SNIM (Société Nationale Industrielle et Minière, Mauritania) in September 2026, then hardened with server-side authentication, input validation and automated tests. Express, MySQL, JavaScript.

Live demo: [projet-im.onrender.com](https://projet-im.onrender.com) (demo account in the repository README)
